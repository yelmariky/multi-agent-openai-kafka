Objet : Demande de devis — Développement logiciel Sprint Juillet 2026 | Plateforme SaaS IA-INSIGHT

Madame, Monsieur,

Nous sommes IA-INSIGHT, éditeur d'une plateforme SaaS multi-tenant d'automatisation administrative à destination des ESN et cabinets de conseil IT. Notre solution intègre des pipelines d'intelligence artificielle (LLM Groq/OpenAI, RAG pgvector) pour automatiser la gestion des notes de frais, CRA mensuels, congés et facturation client.

La plateforme est en production active sur une architecture microservices (Spring Boot 3.3 / Java 21, Kubernetes, Kafka, Keycloak) avec 5 services déployés et 3 consoles web (administrateur, consultant, plateforme).

Objet de la présente demande

Dans le cadre de notre programme de développement sur 4 mois (Juillet – Octobre 2026), nous sollicitons votre société pour la réalisation des 2 sprints du mois de Juillet, correspondant aux livrables suivants :

Sprint 1 — Consolidation architecture & Kong routing (2 semaines)

  • Retrait du code métier dupliqué de ai-service (migration vers expense-service et activity-service)
  • Configuration Kong DB-less : routing des 6 préfixes de path vers les microservices cibles
  • Mise à jour des 3 frontends (config.js → apiBase via Kong)
  • Script de smoke-test automatisé (15 endpoints critiques)
  • Mise à jour de la documentation technique (ENDPOINTS.md, INFRA.md)

Sprint 2 — UX Design System & cohérence 3 frontends (2 semaines)

  • Création d'un Design System CSS unifié (tokens, typographie Space Grotesk, composants)
  • Responsive Mobile First sur les 3 consoles (breakpoints 320 / 768 / 1024 / 1440px)
  • Skeleton loaders animés sur les appels LLM (latence 3–30s)
  • Modale de confirmation réutilisable sur les actions destructives
  • Audit et correction accessibilité WCAG 2.1 AA (Lighthouse ≥ 85)
  • Navigation clavier complète (Tab / Enter / Escape)

Le dossier de conception détaillé (user stories, critères d'acceptation, Definition of Done, architecture) est disponible et sera transmis sur simple demande sous NDA.

Profil recherché

  • Architecture Spring Boot microservices et API Gateway (Kong ou équivalent)
  • Développement frontend Vanilla JS / CSS moderne (pas de framework imposé)
  • Accessibilité web et responsive design

Éléments attendus dans votre devis

  1. Un chiffrage détaillé par livrable (en jours/homme ou forfait)
  2. La composition et le profil de l'équipe proposée
  3. Vos disponibilités de démarrage (date souhaitée : lundi 6 juillet 2026)
  4. Vos références sur des projets similaires (architecture microservices ou SaaS B2B)
  5. Vos conditions générales de prestation (régie / forfait, modalités de recette)
