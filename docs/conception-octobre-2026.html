Multi-tenant

Chaque organisation = 1 realm Keycloak. TenantFilter extrait le realm du JWT → TenantContext (ThreadLocal UUID). Toutes les requêtes JPA filtrent par tenant_id.

Résilience LLM

Groq primaire. Sur 5 échecs / 10 appels → circuit ouvert resilience4j → bascule immédiate OpenAI gpt-4.1-mini. Refermeture 30s. SSE broadcast via Kafka (group-id unique par pod ${HOSTNAME}).

Services AWS retenus & justification

🖥
Amazon EKS (Elastic Kubernetes Service)
Cluster managé — pas de gestion du control plane. Compatible avec tous nos manifests K8s existants (0 réécriture).
System: t3.medium × 2 App: c5.xlarge × 3→8 Auto Scaling Group
🗄
Amazon RDS for PostgreSQL 16 — Multi-AZ
Failover automatique <60s. Extension pgvector supportée. Snapshots quotidiens 7j. Chiffrement at-rest KMS.
Prod: db.r5.large (2vCPU, 16GB) Dev/Staging: db.t3.medium 200GB gp3
📨
Amazon MSK — Managed Kafka
Kafka KRaft managé. Remplace notre Kafka K8s auto-géré. Même API, zéro changement applicatif. Brokers en 3 AZ.
kafka.m5.large × 3 brokers 200GB EBS par broker TLS activé
🔐
AWS Secrets Manager
Remplace Sealed Secrets (Bitnami). Rotation automatique des credentials. Intégration native EKS via IRSA (IAM Roles for Service Accounts).
Secrets: OPENAI_API_KEY, GROQ_API_KEY, DB creds, Keycloak admin
⚖️
Application Load Balancer + AWS WAF
Remplace Kong en entrée. Règles WAF OWASP Core Rule Set. Certificat SSL via ACM (auto-renewal). Path routing vers les services via Ingress K8s.
ALB avec AWS WAF v2 ACM TLS auto-renew Target groups par service
📦
Amazon S3 + ECR
S3 : stockage objets (factures PDF, justificatifs OCR, backups DB). ECR : registre Docker privé pour les 5 images microservices.
S3 Standard-IA (factures >30j) S3 Glacier (archives >1an) ECR scan vulnérabilités

Infrastructure as Code — Terraform

  • Module EKS : cluster, node groups, IRSA, addons (CoreDNS, EBS CSI)
  • Module RDS : instance Multi-AZ, subnet group, security groups, parameter group pgvector
  • Module MSK : cluster, config Kafka, security groups
  • Module ALB + WAF : listener rules, WAF ACL, ACM cert
  • Module S3 : buckets avec versioning, lifecycle policies, encryption KMS
  • Module Secrets Manager : secrets avec rotation policies
  • State Terraform dans S3 + DynamoDB lock
  • Workspaces : dev / staging / prod
  • CI/CD Terraform : plan sur PR, apply sur merge main
  • Tagging AWS obligatoire : Environment, Project, CostCenter, Owner
  • Budget AWS Budgets : alerte si dépense > 120% prévu

Disaster Recovery (DR)

Stratégie Warm Standby

  • Région DR : eu-west-1 (Irlande) — latence <30ms depuis Paris
  • RDS : Cross-Region Read Replica → promotion en <10min en cas de panne Paris
  • MSK : MirrorMaker 2 réplique les topics critiques (platform.notifications, cra.*) vers Irlande
  • S3 : Cross-Region Replication activée (RPO = 15min)
  • EKS DR : cluster standby avec 0 pods (scale-up en 5min via Terraform apply)
  • DNS failover : Route 53 Health Check → bascule automatique si Paris KO >2min
