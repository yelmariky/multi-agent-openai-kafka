⚙️ CONFIGURATION DU CLUSTER
═══════════════════════════════════════════════════════════════════

ARCHITECTURE
  • Mode                : KRaft (Kafka Raft - sans Zookeeper)
  • Nombre de nœuds     : 3 (combinés broker + controller)
  • Namespace K8s       : agent-system
  • Service endpoint    : kafka.agent-system.svc.cluster.local:9092

RESSOURCES PAR NŒUD
  • CPU Request         : 1 core (1000m)
  • CPU Limit           : 2 cores (2000m)
  • Memory Request      : 2Gi
  • Memory Limit        : 4Gi
  • JVM Heap            : 1536m (Xms et Xmx)
  • Stockage Persistent : 20Gi (PVC avec ReadWriteOnce)

RESSOURCES TOTALES (3 nœuds)
  • CPU Total           : 3-6 cores
  • Memory Total        : 6-12Gi
  • Stockage Total      : 60Gi

CONFIGURATION KAFKA
  • Réplication Factor  : 3
  • Min ISR             : 2 (au moins 2 répliques synchronisées)
  • Partitions défaut   : 3
  • Network Threads     : 8 par broker
  • I/O Threads         : 8 par broker
  • Rétention           : 7 jours / 1GB par partition
  • Compression         : Producer-defined
  • GC                  : G1GC optimisé

HAUTE DISPONIBILITÉ
  • Tolérance pannes    : 1 nœud peut tomber sans perte de service
  • Anti-affinity       : Pods distribués sur différents nœuds K8s
  • PDB                 : Maximum 1 pod unavailable simultanément
  • Health Checks       : Liveness et Readiness probes configurés

SÉCURITÉ (ACTUELLE)
  • Listeners           : PLAINTEXT (pas de chiffrement)
  • Authentication      : Non configurée
  • Authorization       : Non configurée
  
  ⚠️  IMPORTANT : Pour la production, activer SSL/TLS et SASL

🚀 DÉMARRAGE RAPIDE
═══════════════════════════════════════════════════════════════════

Suivez ces étapes dans l'ordre :

1. LECTURE DE LA DOCUMENTATION
   $ cat WELCOME.md              # Présentation générale
   $ cat QUICK_START.md          # Guide rapide

2. VÉRIFICATION DES PRÉREQUIS
   $ ./check-prerequisites.sh    # Vérifie kubectl, cluster, etc.

3. INSTALLATION
   $ ./install.sh                # Installe Kafka (~2-3 minutes)

4. VALIDATION
   $ kubectl get pods -n agent-system -l app=kafka
   $ ./test-kafka.sh             # Suite de tests complète

5. MONITORING
   $ ./monitor.sh                # État du cluster
